# IPL-win-probability-predictor
A Machine Learning based web application for predicting IPL match win probability using Python, Streamlit, and Scikit-learn.

## Project Overview
This project predicts the winning probability of IPL teams using Machine Learning.

## Features
- Predict winning probability
- User-friendly interface
- Real-time prediction
- Streamlit web app

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Dataset
- matches.csv
- deliveries.csv

## Files Included
- app2.py
- pipe.pkl
- requirements.txt
- runtime.txt

## How to Run
streamlit run app2.py
